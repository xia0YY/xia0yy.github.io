什么是 LPE？

LPE 原理

LPE（Local Privilege Escalation，本地提权漏洞）是一类允许攻击者从普通用户权限提升到更高权限（如管理员或系统权限）的安全漏洞。攻击者通常已在系统中获得低权限访问，利用此类漏洞进一步控制系统、窃取敏感信息或实现持久驻留。

LPE 常见类型

类型 描述
权限验证缺失或错误 开发者未对敏感操作做权限验证，或验证逻辑存在缺陷
任意文件写入 普通用户可写入系统敏感位置，如 /etc/passwd 或计划任务
DLL 劫持 / 加载 通过放置恶意库文件，在高权限进程中被加载执行
软/硬链接攻击 利用符号链接或硬链接，配合系统任务访问不该访问的文件
SUID 程序利用（Linux） 滥用带有 SUID 权限的程序执行特权命令
注册表 / 服务配置劫持 Windows 系统下对服务的可配置内容做劫持，如 ImagePath
TOCTOU（时间竞争） 在文件检查和使用之间修改资源路径，实现权限绕过
内核漏洞 利用操作系统内核缺陷直接提权，如内存越界、UAF、越权访问

本文重点研究的 Copy-Fail 和 Dirty-Frag 属于 LPE 内核漏洞。

Copy-Fail 漏洞分析

原理

Linux 内存优化机制中，加密通信数据本应写入自己的缓冲区，但 Copy-Fail 漏洞导致写入到了页面缓存中。攻击者可利用该漏洞修改目标文件的内存页（例如 su 命令），从低权限用户提升到 root 用户，实现任意文件读取。

特点：修改仅作用于页面缓存，硬盘文件未改动，重启后恢复，能绕过部分安全检测机制。

Dirty-Frag 漏洞分析

原理

Linux 在发送网络数据时，为提高性能，部分情况下省略了数据复制，使数据包直接引用管道内的页面缓存。当网络协议处理数据（如 IPsec ESP）时，解密结果直接写回内存页面，可能覆盖敏感文件的内存副本，从而实现提权。

攻击特点

  • 需结合 两个漏洞 才能利用完整提权链
  • IPSEC 加密通信协议可向任意可读文件的页面缓存写入四个可控字节
  • 触发条件：创建 用户命名空间 等隔离环境

利用方法

使用 PoC：V4bel/dirtyfrag

修复建议

  • 当前 Linux 发行版尚无官方补丁
  • 临时防护：禁用漏洞模块
